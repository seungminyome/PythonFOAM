Recorded result

The October 13, 2026 run used a serial 20,540-cell case. It requested an observation at step 5 and completed all 10 steps. Each of the four comparison cases produced 45 files byte-identical to the no-request baseline.

Single-run measurements. The callback is synchronous; the solver waits for a response or timeout.

The model repeated the supplied maximum speed but misplaced its location by approximately 0.25 m relative to the actual maximum. These results establish the tested integration, not reliable engineering interpretation.
